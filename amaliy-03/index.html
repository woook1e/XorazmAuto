🧪 Masalalarni Ishga Tushirish

1

Sonlar - raqamlarSoni

1 dan n gacha bo'lgan raqamlarni qo'shish

// raqamlarSoni(5) → 15 // raqamlarSoni(100) → 5050
2

Satrlar - engUzunSoz

Satrda eng uzun so'zni topish

// engUzunSoz("Kitob") → "Kitob" // engUzunSoz("JavaScript asoslari")
3

Massivlar - ikkinchiEngKatta

Ikkinchi eng katta elementni topish

// ikkinchiEngKatta([4,5,3,1]) → 4 // ikkinchiEngKatta([5,5,5]) → 0
4

Satrlar va Sonlar - tubSonlariyigindi

Bank karta raqamini Luhn algoritmi bo'yicha tekshirish

// tubSonlariyigindi("4539 1488 ...") → true
5

Massivlar va Ob'yektlar - diagonallar

Matritsa diagonalini filterlash

// diagonallar([[1,2,3],[4,5,6],...]) // → [1, 5, 9]
