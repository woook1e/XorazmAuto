Yangi

HTML Asoslari

HTML - veb-sahifalarning tuzilishini yaratish uchun ishlatiladigan belgilash tili. Bu veb-developerning asosiy ko'nikmasdir.

O'rganish vaqti: 1-2 hafta

CSS Dizayn

CSS veb-sahifalarni bezash va uslubini boshqarish uchun ishlatiladigan til. Flexbox va Grid kuchli vositalardır.

O'rganish vaqti: 2-3 hafta

JavaScript Dasturlash

JavaScript - veb-sahifalarni interaktiv qilish uchun ishlatiladigan dasturlash tili. Klient-tomonidagi barcha dinamika shu tilda.

O'rganish vaqti: 3-4 hafta
